# Roadmap

## Current Focus

- Trust layer: docs, tests, error codes, generators, release hygiene.
- Keep the official `examples/hello-rpc` path passing.
- Keep published package artifacts installable without workspace protocol.

## Near Term

- Broaden generator coverage only where it supports the verified Next + Nest path.
- Improve Vercel/serverless validation.
- Add more runtime smoke tests around generated manifests and security policies.

## Not Claims

- Wexts is not marketed as field-proven.
- Wexts Shield is not network-level DDoS protection.
- Legacy demos/templates are not production recommendations.
