# Legacy Modernization Archive

This file is retained only as an archive marker for older pre-Wexts-4 work.

- `npx wexts create my-app`
- generated RPC with `@RpcService()` and `@RpcMethod()`
- `useWexts()` on the frontend
- `wexts start` for VPS/Node production runtime
- `wexts vercel-build` for Vercel Build Output API
- Wexts Shield application-layer protection

Do not use this archive as release copy.
