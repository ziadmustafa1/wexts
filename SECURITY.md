# Security Policy

## Supported Versions

Security fixes target the latest published `wexts` and `@wexts/security` versions.

## Reporting

Do not open public issues for sensitive vulnerabilities. Email the maintainer or use GitHub private vulnerability reporting if enabled for the repository.

Include:

- Affected package and version.
- Minimal reproduction.
- Impact.
- Whether credentials or secrets are involved.

## Scope

Wexts Shield provides application-layer controls. Network-level DDoS protection requires Cloudflare, WAF, load balancer controls, or provider protection.
